# Raw source-style datasets

All records in this project are **synthetic** and generated for portfolio / learning use.
They do not represent real customers, employees, or company performance.

Files:
- `leads.csv`: lead-level CRM export.
- `accounts.csv`: account master.
- `opportunities.csv`: one row per opportunity, with current stage and outcome.
- `opportunity_stage_history.csv`: stage-entry events for funnel and velocity analysis.
- `sales_activities.csv`: activity log associated with opportunities.
- `sales_reps.csv`: sales rep dimension.
- `sales_targets.csv`: monthly bookings targets.
- `customers.csv`: won-opportunity customer/ARR records.

The source files intentionally include a small number of CRM data-quality flags to support monitoring exercises.
